## 🚀 Projects

### 🏥 Insurance Cost Prediction

Predicts the medical insurance charges of a person from their age, BMI, smoking status and other details.

![Python](https://img.shields.io/badge/Python-3776AB?style=flat-square&logo=python&logoColor=white)
![scikit-learn](https://img.shields.io/badge/scikit--learn-F7931E?style=flat-square&logo=scikit-learn&logoColor=white)
![Pandas](https://img.shields.io/badge/Pandas-150458?style=flat-square&logo=pandas&logoColor=white)
![MLflow](https://img.shields.io/badge/MLflow-0194E2?style=flat-square&logo=mlflow&logoColor=white)
![Streamlit](https://img.shields.io/badge/Streamlit-FF4B4B?style=flat-square&logo=streamlit&logoColor=white)

| | |
|---|---|
| 🤖 **Model** | Ridge Regression |
| 🎯 **Accuracy (R²)** | 0.91 on test data |
| 📉 **Average error (MAE)** | about 2,267 |
| 📏 **RMSE** | about 4,118 |

| 📂 Dataset | |
|---|---|
| 🧾 **Size** | 1,337 rows |
| 🔢 **Inputs** | age, sex, BMI, children, smoker, region |
| 🎯 **Target** | charges (insurance cost) |
| ✂️ **Split** | 855 train / 214 validation / 268 test |
